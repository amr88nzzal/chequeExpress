# @cheques/words — التفقيط (المبلغ كتابةً)

دوال نقية بلا أي اعتماديات، تحوّل مبلغاً عشرياً (نص) إلى كلمات بالعربية أو الإنجليزية لعملة معيّنة.

```ts
import { amountToWords, JOD } from '@cheques/words';

amountToWords({ amount: '3355.515', currency: JOD, lang: 'ar' });
// "ثلاثة آلاف وثلاثمائة وخمسة وخمسون دينارا و 515 فلس فقط"
```

## قواعد التصميم
- **المبلغ نص عشري دائماً** (`"3355.515"`) ولا يُقبل `number`. التحليل بـ `BigInt` بلا floating point.
- **لا تقريب صامت:** كسور أكثر من خانات العملة (إلا أصفاراً زائدة) ترمي `TOO_MANY_DECIMALS`.
  الاستيراد من الإكسل يجب أن يقرّب القيم القادمة منه (مثل `514.99999999987267`) **قبل** استدعاء هذه الدالة.
- **العملة بيانات** (`currencies.ts`): المفرد والجمع والجنس ووحدة الكسر وعدد الخانات. إضافة عملة = إضافة سطر.
- `fractionStyle`: `numeric` (« و 515 فلس » كما في الإكسل الحالي) أو `words`.
- `closing: false` يحذف «فقط»، لتتحكم فيها قوالب الطباعة.
- حتى 18 خانة للجزء الصحيح.

## الاختبارات
```
pnpm test            # أو: node --test "test/**/*.test.ts"   (Node 22+)
```
- `ar.test.ts` و`en.test.ts`: حالات مكتوبة من قواعد اللغة، ومنها الحالة المأخوذة من ورقة الإكسل.
- `golden.test.ts`: يقارن مع مخرجات وحدة VBA الحالية إذا وُضع الملف `test/golden/jod-ar.csv`
  (يُولَّد بماكرو `tools/TafqeetGoldenExport.bas`). الفروق المقبولة تُوثَّق في `test/golden/known-differences.json`
  بصيغة `{ "201000.000": "السبب" }`. بدون الملف يُتخطّى الاختبار.
- تقرير الفروق: `node tools/compare-golden.ts test/golden/jod-ar.csv`

## الفروق المتوقعة عن وحدة VBA (للمراجعة بعد التصدير)
- 201,000 و202,000 ونحوها: نكتب «مائتا ألف وألف»، والوحدة قد تكتب «مائتان ألف وألف».
- الكسر الرقمي: «5 سنتات» لعملات مثل الدولار (الوحدة تستعمل المفرد دائماً)، ولا فرق للدينار والفلس.
