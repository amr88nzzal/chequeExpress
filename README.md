# ChequeExpress — نظام إدارة الشيكات

نظام ويب متعدد المستأجرين (SaaS) لإدارة **الشيكات الصادرة والواردة** لعدة شركات وبنوك وعملات ودول، مع **طباعة بيانات الشيك الصادر على الشيك الفعلي** (الشيك مرقّم مسبقاً من البنك، يُدخل في طابعة ليزرية، والنظام يطبع الحقول في مواضعها بالمليمتر). المشروع مستقل تماماً ويحلّ محل ملف إكسل يُستخدم اليوم للإدخال والطباعة وتوقع الرصيد.

## المتطلبات

- **Node.js ≥ 22.11** (يستخدم تشغيل ملفات TypeScript مباشرة بلا خطوة بناء).
- **npm ≥ 10** لإدارة الـ workspaces.
- **PostgreSQL ≥ 17** لاختبارات التكامل (RLS والعزل). محلياً عبر PostgreSQL مثبّت أو Docker Desktop، وفي CI كخدمة جاهزة.

## التشغيل

```powershell
# تثبيت الاعتماديات (--ignore-scripts مطلوب في بيئة العمل الحالية، انظر AGENTS.md)
npm install --ignore-scripts --no-audit --no-fund

# التحقق الكامل: أنواع + lint + تنسيق + اختبارات
npm run verify

# اختبارات فقط
npm test

# الواجهة
npm run dev --workspace @cheques/web
```

## الاختبارات

| الأمر                                   | ما يغطّيه                          |
| --------------------------------------- | ---------------------------------- |
| `npm test`                              | اختبارات الوحدة لكل الحزم (Vitest) |
| `npm run typecheck`                     | فحص الأنواع في كل حزمة             |
| `npm run typecheck:root`                | فحص الأنواع للحزم المشتركة والخادم |
| `npm run lint` · `npm run format:check` | الجودة والتنسيق                    |

اختبارات التكامل (العزل بين المستأجرين وRLS) تُشغَّل تلقائياً في GitHub Actions على خدمة PostgreSQL، وتتخطّى نفسها محلياً إن لم يُضبط `DATABASE_URL`. تُشغَّل يدوياً بـ:

```powershell
$env:DATABASE_URL = "postgres://user:pass@127.0.0.1:5432/cheques_test"
npm run migrate --workspace @cheques/api
npm run test:isolation --workspace @cheques/api
```

## القواعد التي لا تُكسر

- **المال:** لا `number` ولا floating point لمبلغ في أي مكان. القاعدة `numeric(18,4)`، والنقل في الـ API كنص عشري، والكود `BigInt` أو نصوص عشرية.
- **عزل المستأجرين:** `tenant_id` في كل جدول بيانات، وRLS مفعّل ومُجبَر، ومستخدم التطبيق ليس مالكاً ولا `BYPASSRLS`، وكل معاملة تبدأ بـ `SET LOCAL app.tenant_id`.
- **لا حذف** لسجلات الشيكات وحالاتها ووظائف الطباعة وسجل التدقيق. الإلغاء حالة لا حذف.
- **تغيير حالة الشيك** يمرّ عبر خدمة واحدة تتحقق من جدول الانتقالات وتكتب تاريخ الحالة في المعاملة نفسها.
- **الطباعة:** كل الأبعاد بالمليمتر، والـ PDF بمقاس الشيك تماماً بلا تحجيم وهوامش، والنص فقط. لا يصير الشيك «مطبوعاً» إلا بتأكيد صريح.
- **التفقيط:** عبارة الإغلاق («فقط» / «فقط لا غير») ليست جزءاً من ناتج التفقيط، بل تُضبط في قالب الطباعة لكل بنك.
