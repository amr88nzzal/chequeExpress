# C0 — المهمة 4: حزمة `cheque-render` (PDF بمقاس الشيك) — تحتاج قياسات الشيك

```
المتطلبات مني قبل البدء: عرض وارتفاع شيك البنك العربي بالمم، وموقع كل حقل (قياسات بالمسطرة)، وموديل الطابعة. إن لم أرسلها فاستعمل مقاساً مؤقتاً صريح التسمية.
أعد كتابة `spikes/pdf-print` بـ Node (Playwright) كحزمة `packages/cheque-render`:
- إخراج PDF بمقاس الصفحة = مقاس الشيك تماماً، نص فقط، وخلفية للمعاينة فقط.
- حاوية مقصوصة `overflow:hidden` وإلا صُغّرت الصفحة عند الإزاحة (درس مكتشف).
- إزاحة وتحجيم من `printer_profile`، ووضعا الورق (ورقة مخصصة / A4 بنقطة أصل).
- خط عربي مضمَّن (اقترح خيارين وسأختار)، وتشكيل سليم للحروف.
- الاختبار الهندسي: مواضع النص ضمن 0.2 مم، **وفيه حالة إزاحة غير صفرية**.
- شغّله داخل حاوية arm64 على السيرفر.
المعيار: الاختبارات خضراء على arm64، وقرار Playwright أم بديل موثّق.
```
